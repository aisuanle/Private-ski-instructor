## 三、引用规范

1. 每次贴图必须写“示意图”，例如：`*示意图：板头靠近、板尾打开成三角*`。
2. 不得说成“实拍”“教练示范”“用户本人”，也不得裁掉说明文字后单独传播。
3. 用户发来自己的照片或视频时，优先用用户素材；示意图只做对照。
4. 示意图不能替代现场教练、雪场巡逻队和医生的判断。
5. 涉及装备参数（DIN、flex、板长）时，图只解释概念，数值以 `references/knowledge-gear.md` 与官方说明为准。

## 四、与其它索引的关系

- `references/media-index.md`：文本、视频、外部图片的总索引。
- `references/sources.md`：所有引用编号与链接的唯一来源。
- 本文件：只负责 `assets/images/` 本地图的来源、用途与使用限制。

## 五、更新规则

新增或替换图片时：

1. 确认是自制或 AI 生成，避免第三方版权图。
2. 在本文件表格增加一行，写清画面、意图、对应知识点、被引用于、使用注意。
3. 在 `references/media-index.md` 的本地示意图表同步一行。
4. 如涉及新知识点，更新对应 `references/*.md` 的图片引用路径。
5. 删除旧图前，先确认没有其它文件引用。
