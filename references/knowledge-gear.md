# 装备知识

> 教练口吻：温柔、平和、不评判；一次只改一件事。详见 `persona.md`。

回答装备问题时先问清：**身高体重、水平、常滑地形、预算、脚型/鞋码**。没有这些信息只能给区间，不能给具体型号。

## 人话速查

- 板子不是越长越好：太长转不动，太短不稳。
- 鞋比板重要：鞋不合脚，技术全白搭。
- 鞋的"硬度"（flex）像鞋帮的支撑力，新手别买最硬的。
- 固定器的"松紧刻度"（DIN）让店里调，自己拧容易受伤。
- 护具先买头盔、护臀、护腕，再谈升级装备。

## 一、双板

| 参数 | 含义 | 选择口径 |
|---|---|---|
| 板长 | 影响稳定与灵活 | 新手常见"身高减 10–15 cm"的经验区间；公园更短、野雪更长 |
| 腰宽（板腰） | 板子中部宽度 | 约 70–80 mm 偏机压/卡宾；85–100 mm 全山；105 mm 以上偏粉雪/野雪 |
| 转弯半径 | 板子设计的最小弯半径 | 小半径（<13 m）灵活；中半径（13–18 m）全能；大半径（>18 m）高速稳定 |
| 板型 | camber / rocker / 混合 | 新手选混合或偏 camber，容错与抓雪兼顾 |
| 靴 flex | 鞋壳硬度指数 | 常见约 70–170；新手/轻体重选低值，竞技选高值 [S24][S25] |
| 固定器 DIN | 释放力矩设定 | 由专业店按 ISO 11088 依体重、身高、水平调整，**不要自行调高** [S23] |

靴子合脚优先于硬度：脚趾轻触鞋头、脚跟不滑动、站立时膝可微屈。

## 二、单板

| 参数 | 含义 | 选择口径 |
|---|---|---|
| 板长 | 影响稳定与操控 | 常见到下巴附近的经验区间；体重、脚码、玩法都会改变选择 |
| 板宽 | 防止脚尖/脚跟拖雪 | 脚码大（EU 44+）选加宽板（wide） |
| 板型 | camber / rocker / flat / 混合 | 新手混合或 flat；粉雪偏 rocker；刻滑偏 camber |
| flex | 板子软硬（常见 1–10） | 新手 3–5；全山 5–7；公园/刻滑按玩法 |
| 固定器角度 | 前后脚角度 | 新手前脚约 15°，后脚 0°～-6°；公园常用对称 duck |
| 站距 | 两脚间距 | 约肩宽；宽站距稳定，窄站距灵活 |
| 靴 | 软硬与贴合 | 新手偏软；刻滑/竞速偏硬 |

## 三、护具

- **头盔**：全程佩戴；选购确认滑雪/单板专用认证（以产品标签为准），并正确系扣。NSAA 雪场安全资料显示 2019–20 雪季约 86% 的滑雪者佩戴头盔 [S6c]；另有雪场统计 2021–22 约 90% [S6d]
- **护目镜**：按透光率（VLT）选镜片；阴天用高透光，晴天用低透光；雪盲防护必要
- **护臀/护膝/护腕**：单板新手优先；公园与竞速加护甲/护背
- **手套**：防水、分指或连指；低温选保暖内衬

## 四、保养

- **打蜡**：按雪温与雪质选蜡；新雪/冷雪用低温蜡，湿雪用暖蜡；刮平、刷出结构
- **修刃**：边刃卷刃及时修；底部划伤用 PTEX 修补
- **存放**：雪季末清洁、擦干、打封存蜡；固定器松开弹簧张力
- **靴**：内衬干燥、避免暴晒；热定型需专业店操作

## 五、买还是租

| 情况 | 建议 |
|---|---|
| 第一次滑雪 | 租：板、靴、头盔；自购手套、护目镜、保暖层 |
| 每季 5–10 天 | 先买靴（合脚最重要），板可租 |
| 每季 10 天以上 | 买全套，按玩法选板 |
| 儿童 | 租或买二手可调板，注意固定器可调范围 |

## 六、常见误区

- "越贵越好" → 高 flex、竞技板对新手是负担
- "DIN 调高更稳" → 增加受伤风险，必须按标准设定
- "头盔越硬越安全" → 合头围、正确佩戴、及时更换更重要
- "板越长越稳" → 超出能力会难以转向
- "二手板不用检查" → 边刃、板底、固定器释放都必须检查
