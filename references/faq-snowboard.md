# 单板常见问题速答

> 教练口吻：温柔、平和、不评判；一次只改一件事。详见 `persona.md`。

用途：用户一次问很多单板问题时，先按编号给一句结论，再展开他关心的那几条。
展开：技术细节读 `discipline-snowboard.md`，装备读 `knowledge-gear.md`，伤情与道外先读 `knowledge-safety.md`。

## 一、入门与站姿（1–10）

| # | 问题 | 速答 |
|---|---|---|
| 1 | 第一次上单板应该先练什么 | 先穿护具上缓坡：单脚适应、直滑、横着刮雪。别急着换刃 [S8] |
| 2 | 单板站姿应该怎么确定前后脚 | 自然站姿让人从背后轻推，先迈出的那只脚就是前脚 |
| 3 | 单板固定器角度对新手有什么影响 | 前脚约 15°，后脚 0°～-6°，以膝踝舒服为准 |
| 4 | 单板两脚固定器角度应该一样吗 | 不必一样。新手前后脚不同更自然，对称 duck 留给公园 |
| 5 | 单板站距宽窄怎么选 | 约与肩同宽。宽一点更稳，窄一点更灵活，先取肩宽 |
| 6 | 单板新手需要先练平衡吗 | 要。先平地单脚站、抬板头，再上缓坡 |
| 7 | 单板在平地怎么单脚滑行 | 只固定前脚，后脚踩板尾蹬地，像滑板推着走 |
| 8 | 单板怎么安全穿脱固定器 | 先穿前脚再穿后脚，站稳或坐下再扣；脱时先解后脚 |
| 9 | 单板摔倒时怎么避免手腕受伤 | 别用手直撑。握拳收臂、侧倒团身，让身体一起落地 |
| 10 | 单板尾骨怎么保护 | 穿护臀，摔时别直坐，先蹲再侧倒 |

## 二、推坡、落叶飘与换刃（11–20）

| # | 问题 | 速答 |
|---|---|---|
| 11 | 单板推坡时重心应该放在哪 | 重心在板面正上方，脚掌均匀踩住，别压脚跟 |
| 12 | 单板后刃推坡总是往后坐怎么办 | 你害怕了。膝盖往前顶、肚子朝山下，双手前伸 |
| 13 | 单板前刃推坡怎么克服恐惧 | 先面朝山下跪着轻推，手扶雪面，数 5 秒匀速 |
| 14 | 单板落叶飘怎么练 | 板子保持横切，只动髋和膝左右移，上身别先倒 |
| 15 | 单板换刃时总是卡刃怎么办 | 换太急了。先放平板 1 秒，再换刃、再立刃，降速练 |
| 16 | 单板换刃应该先转重心还是先转板 | 先移重心到新刃，再让板跟上；上身别抢着转 |
| 17 | 单板转弯时视线应该看哪里 | 看你要去的地方，不看板头；转弯时头先转过去 |
| 18 | 单板怎么控制速度 | 靠弯形和立刃控速，不靠刹车；弯滑圆，速度就稳 |
| 19 | 单板怎么在缓坡连续转弯 | 数节奏：左三秒、右三秒，弯形圆，速度慢 |
| 20 | 单板走刃和搓雪怎么区分 | 走刃留细线、声音细；搓雪雪花大、板底在刮雪 |

## 三、走刃、刻滑与反脚（21–26）

| # | 问题 | 速答 |
|---|---|---|
| 21 | 单板怎么从搓雪过渡到走刃 | 先加大立刃，再让板顺着刃走，别横着推板尾 |
| 22 | 单板立刃角度怎么逐步提高 | 每次只加一点。缓坡大横切，听刃声变细就是对了 |
| 23 | 单板刻滑需要什么基础 | 先连续换刃稳、能随时停，再练大半径横切 |
| 24 | 单板刻滑时膝盖应该怎么发力 | 膝盖跟着板走、往弯心压，别伸直腿硬顶 |
| 25 | 单板反脚需要专门练吗 | 要练。正反脚对称，转身和落地才稳 |
| 26 | 单板怎么练反脚换刃 | 低速反脚横穿，视线和肩线先转，再换刃 |

## 四、平花、跳台与公园（27–38）

| # | 问题 | 速答 |
|---|---|---|
| 27 | 单板平花第一次应该练什么动作 | 先练 ollie 和 butter，在平地找板头板尾平衡 |
| 28 | 单板平花需要哪些护具 | 头盔、护臀、护膝、护腕；上道具再加护甲 [S6] |
| 29 | 单板 Ollie 怎么入门 | 后脚压板尾蓄力，前脚带板起跳，落地屈膝 |
| 30 | 单板 Nollie 和 Ollie 有什么区别 | Ollie 用板尾弹，Nollie 用板头弹，方向相反 |
| 31 | 单板跳台起跳前应该掌握什么 | 连续换刃稳、能直飞小台，还要有人看落地区 [S3b] |
| 32 | 单板跳台起跳时怎么控制重心 | 重心居中略前，起跳点别后坐，眼睛看落地区 |
| 33 | 单板跳台落地总是往前栽怎么办 | 起跳晚了或重心太前。提前 pop，空中收腿，落地屈膝 |
| 34 | 单板跳台落地膝盖怎么缓冲 | 膝盖弯、脚踝放松，别绷直；落地前就先屈膝 |
| 35 | 单板第一次上公园应该选什么道具 | 最小的 box，先 50-50 直上直下，一次一人 [S3b] |
| 36 | 单板 Box 和 Rail 有什么区别 | Box 宽，能平放板；Rail 窄，要板身横跨，更难 |
| 37 | 单板上道具前怎么判断速度 | 先看别人怎么过，再从低速试；能直上直下不减速就够 |
| 38 | 单板道具落地怎么保持稳定 | 眼睛看落点，落地屈膝，重心居中别歪 |

## 五、地形与雪况（39–52）

| # | 问题 | 速答 |
|---|---|---|
| 39 | 单板 U 池需要什么基础 | 先会连续换刃，再练管壁横切和 pump，最后 drop-in |
| 40 | 单板 U 池怎么控制入弯节奏 | 一壁一个节奏：入管屈膝，出管伸展 |
| 41 | 单板波浪道怎么保持节奏 | 提前屈膝吸收，出包伸展，别让包把你弹飞 |
| 42 | 单板蘑菇道怎么选线 | 走雪包背面，别走正面；先慢线，看三步再滑 |
| 43 | 单板粉雪站姿和雪道有什么不同 | 重心略后抬板头，站距略宽，保持速度别停 |
| 44 | 单板粉雪怎么避免扎头 | 速度不够或重心太前。加速、后移一点，板头抬住 |
| 45 | 单板树林滑行应该注意什么 | 先停，别单独钻树。贴同伴走，防树井，迷路就打巡逻队电话 |
| 46 | 单板野雪需要哪些安全装备 | 信标、探杆、雪铲每人一套，加背包和通讯 [S17] |
| 47 | 单板野雪怎么判断雪崩风险 | 先别出发，查当日预报。30° 以上、新雪、背风坡最危险 [S17] |
| 48 | 单板登山滑雪需要什么体能 | 有氧耐力、腿部力量、负重爬升，先练 8 周再上山 |
| 49 | 单板冰面怎么防滑 | 降速、加大立刃、走硬雪边，别在冰上急转 |
| 50 | 单板湿雪怎么调整动作 | 雪黏板会拖速度。重心略前、弯形缩短，打暖蜡 |
| 51 | 单板夜滑视线不好怎么处理 | 换高透光镜片，降速，避开灯影交界，别单独滑 |
| 52 | 单板大风天气怎么滑 | 缆车可能停运。避开风口和堆雪，压低重心慢滑 |

## 六、缆车、礼仪与救援（53–60）

| # | 问题 | 速答 |
|---|---|---|
| 53 | 单板缆车上下怎么安全 | 等椅停稳再上，坐满、脚放脚踏，到站抬板头 [S4] |
| 54 | 单板下缆车总是摔怎么办 | 提前站起、抬板头，落地先直滑，别急着转 |
| 55 | 单板在缆车上怎么固定雪板 | 单脚挂板或抱在身前，别让板子晃到旁边的人 |
| 56 | 单板雪道礼仪有哪些 | 不插队、不占道、摔倒快移边、不闯关闭区 [S3][S4] |
| 57 | 单板超越别人应该从哪边过 | 两边都能过，但要留够空间；后方让前方 [S3][S4] |
| 58 | 单板在雪道中间停留安全吗 | 不安全。移到边上，站到能被上方看见的地方 [S4] |
| 59 | 单板撞人后应该怎么处理 | 先停、救人、叫巡逻队。再交换信息、报雪场、走保险 [S3][S4] |
| 60 | 单板一个人滑雪怎么保证安全 | 雪场内可以，但要告诉人行程；道外绝对不单独去 [S17] |

## 七、人群、体能与心态（61–75）

| # | 问题 | 速答 |
|---|---|---|
| 61 | 单板孩子几岁可以开始学 | 常见 4–6 岁正式学。看注意力和体重，别硬推 |
| 62 | 单板儿童应该请什么类型教练 | 选有儿童教学经验的，或直接报雪场儿童课 |
| 63 | 单板老人学需要注意什么 | 短时、低速、护具齐全。先查心血管和骨密度，别疲劳滑 |
| 64 | 单板膝盖不好还能练吗 | 先问医生。选软板软鞋、避冰面、缩短单次时长 |
| 65 | 单板手腕旧伤怎么防护 | 先停、冰敷、就医。平时戴护腕，摔时别用手直撑 |
| 66 | 单板滑雪前怎么热身 | 5–10 分钟动态：开合跳、髋绕环、高抬腿、踝泵 |
| 67 | 单板滑雪后怎么拉伸 | 滑后静态拉伸小腿、大腿、臀和胸椎，每个 30 秒 |
| 68 | 单板核心力量怎么练 | 平板支撑、死虫、抗旋推拉，每周 3 次 |
| 69 | 单板平衡能力怎么训练 | 单腿站、平衡板、闭眼站，每天 5 分钟 |
| 70 | 单板柔韧性对动作有什么帮助 | 开髋开踝，重心更低、动作更大，也少受伤 |
| 71 | 单板体能训练应该包含什么 | 力量、核心、有氧、平衡、柔韧；雪前 4 周开始 |
| 72 | 单板怎么克服陡坡恐惧 | 先缓坡横切建立节奏，再一段一段下，别一次到底 |
| 73 | 单板怎么克服速度恐惧 | 数数匀速、深呼吸、视线放远，一次只加一点速度 |
| 74 | 单板瓶颈期怎么突破 | 定一个可验收的小目标，拍视频，请一次教练 |
| 75 | 单板看视频复盘应该看什么 | 拍侧面 45°、全身入镜，按入弯、换刃、出弯分段看 |

## 八、竞速与教学（76–85）

| # | 问题 | 速答 |
|---|---|---|
| 76 | 单板怎么选适合自己的教练 | 看 CASI 或国职认证。再看能否说清目标，先试一节课 [S13][S15] |
| 77 | 单板多久能从中级道到高级道 | 常见一到两季。每周稳定滑、有人反馈会更快，因人而异 [S8] |
| 78 | 单板小回转怎么练 | 短弯快节奏，腿转上身稳，弯形圆，先慢后快 |
| 79 | 单板大回转怎么提高 | 高速大弯、连续立刃、线路更直；先稳再快 |
| 80 | 单板竞速训练和自由滑有什么区别 | 竞速练固定线路和计时，自由滑练动作和雪况 |
| 81 | 单板旗门训练怎么入门 | 先练短弯，再上缓坡小旗门，固定线路重复滑 |
| 82 | 单板自由式比赛一般看什么 | 看难度、完成度、多样性和风格，以当日规则为准 |
| 83 | 单板公园礼仪有哪些 | 先看再进、一次一人、不在落地区停留 [S3b] |
| 84 | 单板在公园排队怎么安全 | 排队不抢跳，等前一人离开落地区再上 [S3b] |
| 85 | 单板跳台摔倒后怎么离开落地区 | 先停查伤。能动就快速离开落地区，举手示意后来者 [S3b] |

## 九、装备保养与旅行（86–100）

| # | 问题 | 速答 |
|---|---|---|
| 86 | 单板雪板打蜡频率怎么定 | 每 5–8 次滑或雪况变化就打；滑不动、雪黏板也该打 |
| 87 | 单板雪板刃钝了有什么表现 | 冰面抓不住、转弯打滑、刃线发虚，就该修刃 |
| 88 | 单板固定器需要定期检查吗 | 每年开季、体重变化、租板每次都要检查 [S23] |
| 89 | 单板雪鞋鞋带怎么系才稳 | 从脚背往脚踝依次收紧，脚跟锁住，最后不勒小腿 |
| 90 | 单板雪鞋内胆松了怎么办 | 换系带或加垫；实在松就换鞋，别硬穿大鞋 |
| 91 | 单板租板和买板怎么选 | 第一次租。每季 5 天以上先买鞋，10 天以上再买板 |
| 92 | 单板第一块板应该选什么类型 | 偏软、容错高的全山板；别拿公园板或刻滑板入门 |
| 93 | 单板板长和体重怎么匹配 | 常见到下巴，体重大要加长；最终看板厂体重表 |
| 94 | 单板板型对新手有什么影响 | 混合或 flat 容错高；纯 camber 易卡，纯 rocker 不稳 |
| 95 | 单板软硬度和玩法怎么匹配 | 新手 3–5；全山 5–7；公园偏软，刻滑偏硬 |
| 96 | 单板旅行怎么打包雪板 | 板套装板，衣物填缝，固定器包好，托运前拍照 |
| 97 | 单板国外滑雪需要了解哪些规则 | 先读雪场规则和 FIS 准则。买含滑雪的保险，存好救援电话 [S3][S5] |
| 98 | 单板比赛和自由滑训练怎么平衡 | 赛季比赛占三成，其余打基础；比完复盘再改 |
| 99 | 单板从业余到高手通常要经历哪些阶段 | 会停、会换刃、会刻滑控速、能全山加专项 [S8] |
| 100 | 单板大神平时都练哪些基础 | 每天练刃感、站姿和换刃，专项只占一小部分 [S8] |
