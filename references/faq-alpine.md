# 双板常见问题速答

> 教练口吻：温柔、平和、不评判；一次只改一件事。详见 `persona.md`。

用途：用户一次抛出大量双板问题时，先按编号给一句结论，再对关心的条目展开。
回答仍遵守 `plain-language.md`：先结论、再打比方、术语加括号。

## 一、入门基础

| # | 问题 | 速答 |
|---|---|---|
| 1 | 第一次上双板应该先练什么 | 先练穿脱、平地走、犁式刹车。能停住再上魔毯 [S7] |
| 2 | 双板站姿膝盖应该弯多少 | 微屈到能看见鞋舌。别锁死，也别深蹲 |
| 3 | 双板重心应该放在脚掌还是脚跟 | 全脚掌，略偏前掌。别坐后跟 |
| 4 | 双板新手需要先练走路吗 | 要。平地交替推雪、抬板尾转向，先找板感 |
| 5 | 双板怎么在平地转向 | 抬板尾、板头转向。也可单脚撑地转身体 |
| 6 | 双板怎么正确穿脱雪板 | 先踩脚尖再压脚跟。脱时按后跟杠杆 |
| 7 | 双板摔倒后怎么站起来 | 板横坡、板头朝山下侧。手撑山下侧起身 |
| 8 | 双板摔倒时怎么避免膝盖受伤 | 先停下滑到边上，检查膝盖。疼就找巡逻队；摔时侧倒团身、别用手撑 |

## 二、犁式与平行

| # | 问题 | 速答 |
|---|---|---|
| 9 | 双板犁式刹车怎么练 | 板头靠近、板尾推开成八字。用内刃刮雪，膝微屈 [S10] |
| 10 | 双板犁式转弯怎么入门 | 重心移向山下板，让板自己转。山上板跟进 |
| 11 | 双板犁式总是刹不住怎么办 | 加大板尾开度、多立内刃。还停不住就换缓坡 |
| 12 | 双板从犁式到平行怎么过渡 | 先半犁式收山上板。再把重心交给山下板 [S10] |
| 13 | 双板平行转弯先转腿还是先转重心 | 先移重心到新山下板。腿跟着转，别先甩肩 [S11] |
| 14 | 双板转弯时上身应该怎么保持 | 面朝山下、肩髋稳定。只让腿转 |
| 15 | 双板视线应该看哪里 | 看前方三到五个弯。别盯板头 |
| 16 | 双板怎么控制速度 | 靠弯形和线路，弯滑圆、多横切。别只靠刹车 |
| 17 | 双板怎么在缓坡连续转弯 | 数“一、二、三”的节奏。每个弯滑圆再换 |

## 三、立刃、卡宾与回转

| # | 问题 | 速答 |
|---|---|---|
| 18 | 双板立刃怎么练 | 倾倒加反弓，大半径横切。听刃切的“沙沙”声 [S11] |
| 19 | 双板内刃和外刃怎么区分 | 板内侧是内刃，外侧是外刃。山下板用外刃承重 |
| 20 | 双板卡宾和搓雪有什么区别 | 卡宾刃咬雪、留细线。搓雪板底刮雪、雪花大 [S11] |
| 21 | 双板怎么从搓雪过渡到卡宾 | 先降速，再加大立刃。让板自己画弧，别主动搓 |
| 22 | 双板卡宾时膝盖怎么发力 | 膝踝同步向内压，配合髋部倾倒。别只拧膝盖 |
| 23 | 双板小回转怎么入门 | 先练短弯节奏和点杖。速度慢、弯形圆 [S27] |
| 24 | 双板小回转节奏怎么练 | 数拍子：点杖、换刃、再点杖。保持匀速 |
| 25 | 双板大回转怎么提高 | 先稳线路再加速。每次只改一件事 [S12] |
| 26 | 双板点杖什么时候点 | 入弯前轻点。杖尖落在板头前方 |
| 27 | 双板点杖总是乱怎么办 | 先原地慢练节奏，手腕发力。别用大臂抡 |

## 四、地形、雪况与野雪

| # | 问题 | 速答 |
|---|---|---|
| 28 | 双板蘑菇道怎么选线 | 走包顶或沟底的连线。避开最陡的包面 |
| 29 | 双板蘑菇道怎么吸收雪包 | 到包顶屈膝吸收，下包伸展贴雪。上身保持稳 |
| 30 | 双板猫跳需要什么基础 | 平行转弯稳、能吸收小地形、会点杖 [S10] |
| 31 | 双板粉雪站姿和雪道有什么不同 | 站得更居中略后，双脚并紧。板头稍抬 |
| 32 | 双板粉雪怎么避免雪板交叉 | 双脚同起同落、保持并拢。别单独抬一只板 |
| 33 | 双板树林滑行应该注意什么 | 贴同伴、控速、看两三棵树前的线。别单独钻树 [S4] |
| 34 | 双板野雪需要哪些安全装备 | 信标、探杆、雪铲每人一套。加背包和通讯 [S17] |
| 35 | 双板野雪怎么判断雪崩风险 | 先查当日预报，不确定就不去。坡角 30° 以上、新雪、背风坡最危险 [S17] |
| 36 | 双板登山滑雪需要什么体能 | 有氧耐力、腿臀力量、skin 行走。提前六到八周练 |
| 37 | 双板冰面怎么防滑 | 加大立刃、上身放平、慢速小弯。刃钝先去修 [S23] |
| 38 | 双板湿雪怎么调整动作 | 降速、重心居中、弯形拉长。别硬压板 |
| 39 | 双板夜滑需要注意什么 | 用高透光镜片、降速。不单独滑，注意灯下阴影 |
| 40 | 双板大风天气怎么滑 | 贴地滑、降速、避开风口。缆车停运就别上 |

## 五、缆车与雪道礼仪

| # | 问题 | 速答 |
|---|---|---|
| 41 | 双板缆车上下怎么安全 | 等椅停稳再上，坐满、脚放脚踏。提前抬护栏 [S4] |
| 42 | 双板下缆车总是站不稳怎么办 | 提前站起、板头抬平。顺势滑出，别急转 |
| 43 | 双板在缆车上怎么放雪杖 | 杖横放腿上或交给同伴。别竖着戳人 |
| 44 | 双板雪道礼仪有哪些 | 控速、让前方、摔倒快移边。不闯关闭区 [S3] |
| 45 | 双板超越别人应该从哪边过 | 从上游一侧留出距离，别贴身。下方的人优先 [S3] |
| 46 | 双板在雪道中间停留安全吗 | 不安全。停在可见的边上，别在盲弯停留 [S4] |
| 47 | 双板撞人后应该怎么处理 | 先停下、查看伤者、找巡逻队。再交换信息、报雪场 |
| 48 | 双板一个人滑雪怎么保证安全 | 雪场内可以，但要告诉人行程。道外绝对不单独去 [S3] |

## 六、人群、健康与训练

| # | 问题 | 速答 |
|---|---|---|
| 49 | 双板孩子几岁可以开始学 | 三到四岁玩雪，四到六岁正式学。看注意力和体重 |
| 50 | 双板儿童应该请什么类型教练 | 选有儿童教学法训练的教练。雪场儿童课更合适 |
| 51 | 双板老人学需要注意什么 | 短时、低速、护具齐全。先查心血管和骨密度 |
| 52 | 双板膝盖不好还能练吗 | 先问医生，确认能滑再上雪。戴护膝、选软靴、避冰面 |
| 53 | 双板手腕旧伤怎么防护 | 先问医生。滑时戴护腕、别用手撑、摔倒团身侧倒 |
| 54 | 双板滑雪前怎么热身 | 五到十分钟动态热身。开合跳、髋绕环、侧弓步、踝泵 |
| 55 | 双板滑雪后怎么拉伸 | 静态拉伸腿后、髋、小腿。每个二十到三十秒 |
| 56 | 双板核心力量怎么练 | 平板、死虫、抗旋推。每周两到三次 |
| 57 | 双板平衡能力怎么训练 | 单腿站、平衡板、闭眼站。每天五分钟 |
| 58 | 双板柔韧性对动作有什么帮助 | 开髋、踝背屈、胸椎旋转。幅度更大、动作更省力 |
| 59 | 双板体能训练应该包含什么 | 力量、有氧、平衡、柔韧。雪前四周开始 |
| 60 | 双板怎么克服陡坡恐惧 | 先横切、数节奏，只看前方三个弯。小步加难度 |
| 61 | 双板怎么克服速度恐惧 | 缓坡匀速数数、深呼吸。一次只加一点速度 |
| 62 | 双板瓶颈期怎么突破 | 定一个可验收的小目标。拍视频，请一次教练 |
| 63 | 双板看视频复盘应该看什么 | 侧面 45° 全身入镜。按入弯、过渡、出弯分段看 |
| 64 | 双板怎么选适合自己的教练 | 看认证（PSIA 或国职）、能否说清目标。先试一节课 [S10] |
| 65 | 双板多久能从中级道到高级道 | 因人而异，通常二十到四十个雪日。关键在连续平行和控速 [S7] |

## 七、公园、跳台与竞速

| # | 问题 | 速答 |
|---|---|---|

| 67 | 双板跳台起跳前需要掌握什么 | 平行转弯稳、能直飞小台。会落地缓冲 [S3b] |
| 68 | 双板跳台落地怎么缓冲 | 空中收腿，落地屈膝吸收。重心居中，别后坐 |
| 69 | 双板公园道具怎么安全尝试 | 从小 box 开始，先做 50-50。正面直上直下，一次一人 [S3b] |
| 70 | 双板 U 池需要什么基础 | 先练管壁横切和 pump。再学 drop-in 和出管 |
| 71 | 双板波浪道怎么保持节奏 | 提前屈膝吸收，出包伸展。保持匀速 |
| 72 | 双板雪包地形怎么通过 | 膝盖当弹簧、板头贴雪。点杖稳住节奏 |
| 73 | 双板竞速训练和自由滑有什么区别 | 竞速练固定线路和计时。自由滑练动作和雪况适应 |
| 74 | 双板旗门训练怎么入门 | 先小回转旗门、固定线路。慢速走线再计时 [S12] |
| 75 | 双板回转比赛一般看什么 | 看线路选择、立刃连续性。还看过门稳定和总时间 |
| 76 | 双板公园礼仪有哪些 | 排队有序、一次一人。落地后快离开，不逆行 [S3b] |
| 77 | 双板在公园排队怎么安全 | 在入口外等，别站落地区。前者落地离开再进 [S3b] |
| 78 | 双板跳台摔倒后怎么离开落地区 | 先确认没伤，疼就呼救。再快速爬到边上，举手示意 |

## 八、装备

| # | 问题 | 速答 |
|---|---|---|
| 79 | 双板雪板打蜡频率怎么定 | 每五到十个雪日打一次，滑不动时也该打。按雪温选蜡 |
| 80 | 双板雪板刃钝了有什么表现 | 冰面打滑、转弯发虚、刃线不干净。及时修刃 |
| 81 | 双板固定器需要定期检查吗 | 要。每年开季、体重变化、租板每次都要按标准调 [S23] |
| 82 | 双板雪鞋扣怎么调才合适 | 从下往上扣，紧到脚跟不抬、脚不麻 [S24][S25] |
| 83 | 双板雪鞋内胆松了怎么办 | 换薄袜或加鞋垫。仍松就找店热定型或换鞋 [S26] |
| 84 | 双板租板和买板怎么选 | 第一次租。每季五到十天先买鞋，十天以上买全套 |
| 85 | 双板第一块板应该选什么类型 | 容错型全山板，腰宽 80–90 mm。偏软好上手 [S24] |
| 86 | 双板板长和身高体重怎么匹配 | 新手常见身高减 10–15 cm。体重大往上加 [S7] |
| 87 | 双板板型对新手有什么影响 | 选混合或偏 camber。容错和抓雪兼顾 |
| 88 | 双板软硬度和玩法怎么匹配 | 软板好上手练动作，硬板稳但费力。按玩法选 |
| 89 | 双板雪杖长度怎么选 | 握杖直立，杖尖触地时肘约 90°。太长会拖地 |
| 90 | 双板旅行怎么打包雪板 | 板底对板底、刃包好。放板包中层，别压固定器 |
