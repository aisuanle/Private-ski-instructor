# 装备常见问题速答

> 教练口吻：温柔、平和、不评判；一次只改一件事。详见 `persona.md`。

用途：用户一次抛出大量装备问题时，先按编号速答，再对关心的条目展开。
回答只给区间不给型号；具体参数以产品标签和专业店判断为准。

## 一、装备体系与租买

| # | 问题 | 速答 |
|---|---|---|
| 1 | 单板和双板装备体系最大区别是什么？ | 单板是板+固定器+软靴；双板是两板+释放固定器+硬靴。双板固定器要看 DIN 值，单板没有。 |
| 2 | 第一套滑雪装备应该先买什么？ | 先买合脚的雪鞋和滑雪袜，再买头盔、雪镜、手套。板子最后买。 |
| 3 | 滑雪装备租和买分别适合什么情况？ | 一季 1–3 天租全套；5–10 天先买鞋；10 天以上再考虑买板。 |
| 4 | 新手买雪板最容易犯什么错？ | 贪长、贪硬、贪贵。超出能力的板转不动，也更容易摔。 |

## 二、雪板与固定器

| # | 问题 | 速答 |
|---|---|---|
| 5 | 雪板长度应该怎么选？ | 双板常见“身高减 10–15 cm”；单板常见到下巴附近。体重大的往上加。 |
| 6 | 雪板宽度对滑行有什么影响？ | 双板腰宽 70–80 mm 偏机压，85–100 mm 全山，105 mm 以上偏野雪。越宽越浮雪，转向越慢。 |
| 7 | 雪板板型怎么选？ | 新手选 camber 或混合板型，抓雪又容错。粉雪偏 rocker，刻滑偏 camber。 |
| 8 | 雪板软硬度怎么选？ | 单板新手 flex 3–5，全山 5–7。体重轻、速度慢都选软一点。 |
| 9 | 单板板型和双板板型选择逻辑有什么不同？ | 单板更看板型和 flex 配玩法；双板更看腰宽和转弯半径配地形。 |
| 10 | 公园板、全山板、刻滑板怎么区分？ | 公园板短而软、双板头；全山板中等腰宽；刻滑板硬、窄腰、抓边刃。 |
| 11 | 双板道内板、全山板、野雪板怎么选？ | 道内板腰宽 70–80 mm；全山 85–100 mm；野雪 105 mm 以上。 |
| 12 | 单板固定器角度怎么定？ | 新手前脚约 15°、后脚 0°～-6°。公园常用 ±15° 对称。 |
| 13 | 单板固定器站距怎么调？ | 先按肩宽，再按舒适微调。宽站距稳，窄站距灵活。 |
| 14 | 单板固定器软硬怎么选？ | 新手选中软；公园选软；刻滑选硬。 |
| 15 | 双板固定器DIN值怎么定？ | 必须由专业店按 ISO 11088 依体重、身高、水平调，别自己拧高 [S23][S23b]。 |
| 16 | 双板固定器需要每年检查吗？ | 要。每年开季做一次释放测试，体重变了要重调 [S23][S23b]。 |
| 17 | 固定器安装位置对滑行有什么影响？ | 装前一点好转弯，装后一点更稳。按厂家推荐位装，别乱移。 |

## 三、雪鞋与滑雪袜

| # | 问题 | 速答 |
|---|---|---|
| 18 | 雪鞋硬度怎么选？ | 双板靴 flex 常见 70–170；新手和轻体重选低值，竞技选高值 [S24][S25]。单板靴新手偏软。 |
| 19 | 单板雪鞋和双板雪鞋尺码怎么选？ | 按脚长（mm）选，别按运动鞋码。双板靴壳内脚跟后留约 10–15 mm [S25][S26]。 |
| 20 | 雪鞋太紧会有什么问题？ | 压脚背、发麻、血流不畅。紧了换宽楦或大半码。 |
| 21 | 雪鞋太松会有什么问题？ | 脚跟抬、控不住板，还容易磨水泡。松了先系紧、加垫。 |
| 22 | 单板雪鞋鞋带系统怎么选？ | 新手选抽绳快速系带，省力。传统系带便宜可微调，BOA 方便但别拉过紧。 |
| 23 | 双板雪鞋扣怎么调？ | 从下往上扣，脚背扣留一点余量，小腿扣收紧；扣完不麻才对 [S24]。 |
| 24 | 雪鞋热塑有必要做吗？ | 脚型特殊、压痛点明显才做，找专业店热定型。 |
| 25 | 雪鞋内胆如何保养？ | 每次滑完取出内胆晾干，别暴晒，别用烘干机高温烤。 |
| 26 | 滑雪袜应该多厚？ | 薄到中等厚即可，脚趾和胫骨处不能有褶皱。太厚反而挤脚。 |
| 27 | 滑雪袜为什么不能穿棉袜？ | 棉吸汗不排汗，湿了更冷还磨脚。选羊毛或化纤混纺。 |

## 四、服装与手套

| # | 问题 | 速答 |
|---|---|---|
| 28 | 滑雪服防水和透气怎么权衡？ | 看防水（mm）和透气（g/m²/24h）。日滑选 10,000 mm 起，野雪选更高。 |
| 29 | 滑雪服尺码应该选紧还是松？ | 外层留一层中层空间，别太紧也别太肥。试穿要能抬臂、能蹲下。 |
| 30 | 滑雪服里面怎么分层穿？ | 三层：排汗层、保暖层、防水外层。别穿纯棉内衣。 |
| 31 | 速干层、保暖层、外壳层怎么搭配？ | 贴身速干排汗，中层抓绒或薄棉，外层防风防水；冷再加一层。 |
| 32 | 滑雪裤背带款和普通款怎么选？ | 背带款不进雪、跳跑不掉；普通款方便上厕所。野雪选背带。 |
| 33 | 滑雪服雪裙有什么用？ | 挡住摔倒灌进来的雪。滑粉雪、常摔时把雪裙扣好。 |
| 34 | 滑雪服口袋怎么安排更安全？ | 手机放贴身内袋，雪票放外袋，钥匙别和手机同袋。 |
| 35 | 滑雪手套分指和连指怎么选？ | 分指灵活，连指更暖。新手选防水分指或三指。 |
| 36 | 手套防水和保暖怎么权衡？ | 先保防水，再按温度加内衬。湿手套再厚也不暖。 |
| 37 | 手套内衬湿了怎么办？ | 回室内翻面晾干，别贴暖气烤。备一副替换内衬。 |

## 五、头盔与雪镜

NSAA 雪场统计显示，戴头盔比例约 86%（2019–20 季）[S6c]、约 90%（2021–22 季）[S6d]；戴了也要控速。

| # | 问题 | 速答 |
|---|---|---|
| 38 | 头盔应该怎么选尺码？ | 量头围（cm）选对应尺码，戴上不夹头、不晃动，扣好下巴带 [S6]。 |
| 39 | 头盔和雪镜怎么匹配？ | 雪镜宽度别超过盔沿，镜框贴住头盔不留缝。 |
| 40 | 头盔需要多久更换？ | 一般 5 年左右，或按厂家标注年限；撞击后立即换 [S6]。 |
| 41 | 头盔受过撞击还能用吗？ | 不能再用。缓冲层可能已失效，以产品标签和专业店判断为准 [S6]。 |
| 42 | 雪镜镜片颜色怎么选？ | 颜色主要影响对比度，不只影响亮度。阴天偏黄或玫瑰，晴天偏灰或绿。 |
| 43 | 雪镜透光率怎么选？ | 晴天用低 VLT%（约 8–20%），阴天用高 VLT%（约 40–80%）。 |
| 44 | 雪镜起雾怎么预防？ | 别用手擦内侧，开通风口，滑完晾干。双层镜片更防雾。 |
| 45 | 雪镜和近视眼镜怎么搭配？ | 选 OTG 雪镜，能直接套在眼镜外；镜框别选太宽。 |
| 46 | 雪镜可以配近视镜片吗？ | 可以。选内置光学镜片（insert）的型号，按度数定制。 |
| 47 | 雪镜带怎么调才不漏风？ | 带子压头盔外侧、贴住盔沿，别夹在头盔和头之间。 |

## 六、护具与背包、雪崩装备

| # | 问题 | 速答 |
|---|---|---|
| 48 | 护臀裤怎么选？ | 单板新手必买，看尾骨和坐骨处加厚，尺码贴合不滑动。 |
| 49 | 护膝怎么选？ | 看屈膝时是否贴合、防撞够不够，别太厚影响弯膝。 |
| 50 | 护腕对单板新手有必要吗？ | 很有必要，单板初学手腕伤最多。选带硬支撑片的。 |
| 51 | 护甲对公园和野雪有必要吗？ | 公园、竞速、野雪建议穿，防撞也防树枝。道内休闲可省。 |
| 52 | 护具穿在滑雪服里面还是外面？ | 护具贴身、穿在滑雪服里面，别外穿影响活动。 |
| 53 | 护具尺码不合会有什么风险？ | 太大易滑动、保护错位；太小勒血流。宁可选可调尺码。 |
| 54 | 滑雪背包怎么选容量？ | 日滑 10–20 L，野雪 20–30 L，多日 30 L 以上。 |
| 55 | 背包需要兼容头盔吗？ | 要。选能外挂头盔或带盔兜的款式，别硬塞进包。 |
| 56 | 野雪背包需要哪些功能？ | 雪铲仓、探杆仓、信标口袋、胸带哨子、腰带口袋 [S17]。 |
| 57 | 雪崩三件套包括什么？ | 信标、探杆、雪铲，每人一套，缺一不可 [S17]。 |
| 58 | 雪崩信标怎么佩戴？ | 贴身内层、开在发送模式，别放背包里；出发前互检 [S17]。 |
| 59 | 探杆和雪铲怎么选？ | 探杆选 240–320 cm 可调，雪铲选金属铲头、长度够挖。 |
| 60 | 气囊背包适合什么人？ | 常去道外、陡坡和树林的人。它提高存活率，但不能替代判断。 |
| 61 | 对讲机滑雪时怎么选？ | 选防水、耐低温、续航 8 小时以上，配耳麦更方便。 |
| 62 | 手机在低温下怎么防关机？ | 贴身内袋保温，开省电模式，随身带充电宝。 |
| 63 | 滑雪时运动相机怎么固定？ | 用头盔底座或胸带，别用长杆乱挥。固定好先晃一晃试牢。 |

## 七、保养与清洁

| # | 问题 | 速答 |
|---|---|---|
| 64 | 雪板蜡有哪几种？ | 按雪温分：冷雪用低温蜡，湿雪用暖蜡，另备封存蜡。 |
| 65 | 雪板多久打一次蜡？ | 一般滑 5–10 天打一次；板底发白、滑不动就补。 |
| 66 | 自己打蜡需要哪些工具？ | 熨斗或刮蜡器、刮板、刷子、蜡。温度别高到烫坏板底。 |
| 67 | 雪板刃怎么修？ | 卷刃先用锉刀或修刃器顺一个方向修，再抛光。 |
| 68 | 雪板存放前需要做什么？ | 擦干、去污、打封存蜡，固定器松开弹簧张力。 |
| 69 | 雪板夏天怎么存放？ | 阴凉干燥处竖放或平放，别压弯、别暴晒、别靠暖气。 |
| 70 | 雪鞋怎么晾干？ | 取出内胆、翻面通风晾干，别暴晒、别高温烘。 |
| 71 | 雪镜怎么清洁？ | 外侧用清水或专用清洁液擦，内侧只轻擦，别干蹭。 |
| 72 | 头盔怎么清洁？ | 温水加中性洗涤剂擦外壳，内衬按厂家说明拆洗 [S6]。 |
| 73 | 滑雪服怎么洗？ | 按洗标走，用中性洗剂，少用柔顺剂，别频繁洗。 |
| 74 | 滑雪服能用烘干机吗？ | 看洗标。低温烘干能恢复防泼水，高温会伤涂层。 |
| 75 | 羽绒服和棉服做滑雪保暖层怎么选？ | 干冷选羽绒，湿冷选化纤棉；出汗多也选化纤。 |
| 76 | 电加热手套和电加热雪鞋值得买吗？ | 手脚易冻、常滑极寒才值。电池和线路要看防水。 |

## 八、人群与特殊需求

| # | 问题 | 速答 |
|---|---|---|
| 77 | 滑雪装备有哪些高性价比入门选择？ | 先租板靴，买好头盔、雪镜、手套；雪鞋买合脚的中低端款。 |
| 78 | 儿童滑雪装备怎么选？ | 优先租或买可调二手，孩子长得快。固定器要能按体重重调 [S23]。 |
| 79 | 儿童雪板长度怎么选？ | 双板常见到下巴到鼻子高，单板到胸口；宁短勿长。 |
| 80 | 儿童头盔和护具怎么选？ | 头盔按头围选并扣好，护腕护臀按体重尺码，别买大号凑合 [S6]。 |
| 81 | 老人滑雪装备应该注意什么？ | 选软靴、轻板，护具齐全；出发前先查骨密度和心血管。 |
| 82 | 近视滑雪者装备怎么配？ | OTG 雪镜套眼镜，或上内置近视镜片。别戴普通墨镜滑。 |
| 83 | 宽脚和高脚背怎么选雪鞋？ | 选宽楦（last 约 102–104 mm），高脚背选可调鞋舌或做热塑 [S24][S26]。 |
| 84 | 大体重滑雪者雪板怎么选？ | 板加长、选偏硬，固定器 DIN 按体重重调 [S23]。 |
| 85 | 小体重滑雪者雪板怎么选？ | 板偏短偏软，DIN 调低，别硬上成人硬板 [S23]。 |
| 86 | 高个子滑雪者雪板怎么选？ | 按身高区间取上限，站距和固定器位置也适当放宽。 |
| 87 | 女性滑雪装备有哪些选择差异？ | 女款靴楦和小腿形状更贴，板偏轻。按体重选长度，别只看身高 [S24]。 |

## 九、二手、托运与旅行升级

| # | 问题 | 速答 |
|---|---|---|
| 88 | 滑雪装备二手交易要注意什么？ | 查生产年份、边刃板底、固定器可调范围；头盔别买二手 [S6]。 |
| 89 | 二手雪板怎么看磨损？ | 看板底深划伤、边刃卷刃、板头板尾是否分层。伤太深就放弃。 |
| 90 | 二手雪鞋能不能买？ | 可以，但要试穿，查内胆和扣具；热塑过的看壳形有没有变形。 |
| 91 | 二手头盔能不能买？ | 不建议。撞击史和老化看不出来，以产品标签和专业店判断为准 [S6]。 |
| 92 | 雪板托运怎么包装？ | 用板包加气泡膜，板头板尾加护角，固定器拆下或包好。 |
| 93 | 雪板飞机托运有什么限制？ | 按航司行李规定，超长要申报。出发前查尺寸和费用。 |
| 94 | 滑雪旅行装备清单应该包括什么？ | 板靴杖、头盔雪镜、手套袜、三层衣、护具、蜡具和证件。 |
| 95 | 雪场租装备怎么检查安全性？ | 查边刃、板底、固定器释放、靴扣；让店员按体重调 DIN [S23]。 |
| 96 | 租来的雪鞋不合脚怎么办？ | 立刻换。别将就，磨脚会毁掉一整天。 |
| 97 | 租板需要告诉店员哪些信息？ | 身高体重、鞋码、水平、常滑地形、这次想练什么。 |
| 98 | 装备升级应该按什么顺序？ | 鞋、头盔雪镜、板、固定器。鞋最影响技术。 |
| 99 | 装备和技术的提升应该怎么匹配？ | 先练到能稳定控速，再换硬板硬靴。装备别超前技术太多。 |
| 100 | 从业余到高手装备配置通常怎么变化？ | 从全能软板到按玩法分板，靴 flex 逐步提高，护具更专业。 |
